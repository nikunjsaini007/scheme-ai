# Yojantra: Your Benefits

Create a premium, award-winning website for an Indian citizen benefits and government scheme discovery platform called:

YOJANTRA

Tagline:

“Discover the benefits meant for you.”

Secondary tagline:

“India has thousands of government schemes. Yojantra helps you find the ones you can actually benefit from.”

IMPORTANT:

Use the attached reference images as VISUAL INSPIRATION only.

Do NOT copy the exact website, layout, text, branding, imagery, or components from the references.

Instead, capture the same design philosophy:

- editorial web design

- oversized typography

- asymmetric compositions

- premium storytelling

- warm off-white backgrounds

- bold orange accent

- large photography

- overlapping cards

- dramatic typography

- generous whitespace

- smooth scroll animations

- sophisticated transitions

- magazine/editorial aesthetic

- minimal navigation

- premium visual hierarchy

The website should feel like an Awwwards-level product rather than a typical government portal.
